# TeleBirr Transaction Report

This mini-project creates a simple transaction report for an Addis shop using JavaScript array methods, destructuring, spread syntax, and modules.

## Files

### transactions.js

Contains the TeleBirr transaction data.

### report.js

Contains functions for calculating transaction totals and formatting receipts.

### app.js

Imports the data and functions and prints the final report.

## JavaScript Concepts Used

- filter()
- map()
- reduce()
- Destructuring
- Spread syntax
- ES Modules
