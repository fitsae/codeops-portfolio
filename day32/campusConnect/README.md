# CampusConnect 🎓

CampusConnect is a React-based **Student Community Portal** designed to help students discover campus clubs, upcoming events, and useful student resources in one place.

The project demonstrates modern React development concepts including reusable components, props, state management, controlled forms, data fetching, React Router, dynamic routes, search/filtering, conditional rendering, and Context API.

---

## 📌 Project Overview

Campus life includes many opportunities outside the classroom, but students may have difficulty finding information about clubs, events, and available services.

CampusConnect provides a centralized platform where students can:

- Discover student clubs
- Search for clubs
- View detailed club information
- Save favorite clubs
- Discover upcoming campus events
- View detailed event information
- Access useful student resources
- Navigate between pages using React Router
- Find a personalized list of favorite clubs

---

## ✨ Features

### 🏠 Home Page

The homepage provides an overview of the campus community.

It includes:

- Welcome/hero section
- Featured events
- Popular clubs
- Quick student resources
- Navigation links to major sections

Popular clubs are determined using the number of club members.

---

### 🏛️ Clubs

The Clubs page displays available student clubs.

Each club includes:

- Club name
- Description
- Category
- Image
- Number of members
- Favorite button
- Link to detailed club information

Students can also search for clubs by name.
