# 💰 Birr Budget

A modern, responsive personal finance dashboard for managing income and expenses in Ethiopian Birr (ETB).

Birr Budget is a front-end web application built with **HTML, CSS, JavaScript, and JSON**. It allows users to record, search, filter, sort, edit, and delete financial transactions while automatically calculating their total income, expenses, and current balance.

---

## 📌 Project Overview

Managing personal finances can be difficult when transactions are recorded in different places.

**Birr Budget** provides a simple dashboard where users can manage their financial activity in one place.

The application supports:

- 💵 Income tracking
- 💸 Expense tracking
- 📊 Automatic financial summaries
- 🔎 Transaction search
- 🏷️ Category filtering
- 📅 Date sorting
- ➕ Adding transactions
- ✏️ Editing transactions
- 🗑️ Deleting transactions
- 💾 Local data persistence
- 🌙 Dark mode
- 📱 Responsive design
- ⚠️ Loading, error, and empty states

The application is designed to work across:

- 📱 Mobile phones
- 📲 Tablets
- 💻 Laptops
- 🖥️ Desktop computers

---

# 🎯 Project Objectives

The main objectives of Birr Budget are to:

1. Build a practical personal finance management application.
2. Practice semantic HTML.
3. Apply responsive CSS using Flexbox, Grid, and media queries.
4. Load structured data from a JSON file using JavaScript.
5. Manipulate the DOM dynamically.
6. Implement search, filtering, and sorting.
7. Implement CRUD operations.
8. Practice JavaScript state management.
9. Use `localStorage` for persistent browser data.
10. Implement client-side form validation.
11. Implement a responsive dark-mode interface.
12. Create a clean and accessible user interface.

# 🛠️ Technologies Used

| Technology   | Purpose                                     |
| ------------ | ------------------------------------------- |
| HTML5        | Page structure and semantic markup          |
| CSS3         | Styling, layout, responsiveness, animations |
| JavaScript   | Application logic and DOM manipulation      |
| JSON         | Initial transaction dataset                 |
| Fetch API    | Loading JSON data                           |
| LocalStorage | Persisting user changes                     |
| CSS Grid     | Dashboard and responsive layouts            |
| Flexbox      | Component alignment                         |
| HTML Dialog  | Add/Edit transaction modal                  |

No backend server or database is required.
